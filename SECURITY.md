# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately to Comeback Technologies LLC using GitHub's
**private vulnerability reporting** for this repository (Security → Report a vulnerability). Do not
open a public issue, and do not include real user or participant data in reports.

We aim to acknowledge reports within 5 business days. Threshold has not been publicly released, so
there are no supported production versions yet.

## Scope

The iPhone app, the watch app, the optional backend and the research pipelines in this repository.
Controls and known gaps are documented in [documentation/SECURITY.md](documentation/SECURITY.md) and
[documentation/THREAT_MODEL.md](documentation/THREAT_MODEL.md).
